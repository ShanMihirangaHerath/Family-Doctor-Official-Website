# Family Doctor Health - Official Website 🏥

![Family Doctor Health](public/mylogo.png)

Welcome to the official web repository for **Family Doctor Health (Pvt) Ltd**. This project is a modern, responsive, and highly interactive web application built to showcase our digital healthcare ecosystem. It connects patients with doctors, pharmacies, laboratories, and physiotherapy centers while offering features like SOS alerts, medical records via QR code, and smart medication reminders.

## 🚀 Tech Stack

### Frontend
* **React.js** - UI Library
* **Vite** - Next Generation Frontend Tooling
* **Tailwind CSS** - Utility-first CSS framework for rapid UI development
* **Framer Motion** - Production-ready animation library for React (Used for 3D sliders & micro-interactions)
* **Lucide React** - Beautiful & consistent icon toolkit
* **React Router DOM** - Declarative routing

### Backend (Microservice for Contact Form)
* **Node.js & Express** - Lightweight server environment
* **Nodemailer** - Secure email delivery module

---

## ✨ Key Features

* **Modern UI/UX:** Clean, responsive design featuring glassmorphism and smooth gradient overlays.
* **Infinite 3D Carousel:** A dynamic, auto-scrolling framer-motion slider showcasing the Family Doctor mobile app interface.
* **Live Contact Form:** Real-time email delivery system using a custom Node.js backend.
* **Floating WhatsApp Support:** Instant customer support widget with auto-generated contextual messaging.
* **Comprehensive Legal Pages:** Fully formatted Privacy Policy and Terms of Service pages aligned with Sri Lankan PDPA regulations.

## 🛠️ Installation & Setup

To run this project locally, you will need to start both the Frontend development server and the Node.js Backend server.

### Prerequisites
* Node.js (v16.x or higher recommended)
* npm or yarn

### 1. Frontend Setup (React + Vite)
Open your terminal and navigate to the root directory of the project.

```bash
# Install dependencies
npm install

# Start the Vite development server
npm run dev
